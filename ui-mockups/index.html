设计决策要点

  • 暗色为默认——相机场景多为低光、现场、影棚，深底减少眩光；纯黑 (#000) 只用在 Live View 全屏区，其他用 #09090b 避免 OLED 上的死黑。
  • 主色琥珀 #e8b455——刻意避开 SnapBridge/佳能/大疆常见的科技蓝，与胶片/电影调子契合，且在暗背景下饱和不刺眼。
  • 数字全用等宽体——ISO/快门/光圈/文件名/进度都用 JetBrains Mono，避免可变宽字体带来的"跳动感"。
  • 信息密度分层——Live View HUD 用毛玻璃 chip 悬浮，不遮挡画面；参数抽屉从底部上滑，遵循 iOS 手势习惯。
  • 连接可视化——PTP-IP 握手细节以日志形式展示（可折叠），debug 期能直接看到卡在哪一步（InitCommandRequest → Ack → ChangeApplicationMode）。
  • USB / Wi-Fi 双通道明确区分——绿色 badge = USB、蓝色 = Wi-Fi，跨屏一致，用户永远知道当前走的哪条路。
  • 兜底路径始终可达——手动 IP 输入 + USB 切换按钮出现在连接向导底部，覆盖 Android 权限拒绝、iOS Wired Accessories 拒绝、mDNS 失败等场景。
